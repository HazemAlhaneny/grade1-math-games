# ألعابي مع الأعداد — الصف الأول

موقع تعليمي بسيط وتفاعلي لطلاب الصف الأول.

- الأعداد من ١ إلى ٩ بالأرقام العربية.
- لعبة جمع وطرح ضمن العدد ٥.
- لعبة ترتيب الأعداد من الأصغر إلى الأكبر.
- إعداد المعلم: جميل سكاكية.
- المدرسة: غازي القواسمة.

## نشر الموقع على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملف `index.html` إلى المستودع.
3. من **Settings → Pages** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
5. بعد دقائق سيظهر رابط الموقع من GitHub Pages.
